How to Play

Each node in the network is a Harry Potter character. Your job is to figure out who's who using the connections between them.

  • Click a node to select it — you'll see how many connections it has and which revealed characters it's linked to.
  • Pick a name from the sidebar to make your guess.
  • You get 3 attempts per character. After 3 wrong guesses, the name is revealed.
  • Node size = importance (bigger nodes are more central characters).
  • Connections mean two characters share significant scenes together. Thicker lines = more shared screen time.
  • Colours represent houses — see the legend in the bottom left.

Tip: start with the biggest, most connected nodes — they're the easiest to identify. Use revealed names to figure out their neighbours.
